# Phase 2 Result Analysis

Date updated: 2026-03-15

## Current headline findings
1. The full core benchmark is complete for `4 models x 3 seeds = 12 runs`.
2. The current ranking is:
   - `resnet18`
   - `efficientnet_b0`
   - `vit_small_patch16_224`
   - `resnet50`
3. Mean results:
   - `resnet18`: accuracy `0.99817`, macro F1 `0.99845`
   - `efficientnet_b0`: accuracy `0.99795`, macro F1 `0.99824`
   - `vit_small_patch16_224`: accuracy `0.99731`, macro F1 `0.99757`
   - `resnet50`: accuracy `0.99623`, macro F1 `0.99614`

## Interpretation
1. These results are very strong, but they are also broadly expected on PlantVillage.
2. PlantVillage is a clean, curated, high-ceiling dataset, so near-saturated accuracy is not unusual.
3. `resnet18` winning is a credible outcome rather than a surprising one; a smaller CNN can be a better fit than a larger model on a structured task like this.
4. `efficientnet_b0` is especially attractive from a deployment/efficiency perspective because it stays very close to the top result while using a much smaller checkpoint.
5. `vit_small_patch16_224` performing well but not winning is still a useful result. It gives the dissertation something real to discuss instead of a trivial “transformers always win” story.
6. `resnet50` finishing last despite being larger supports the claim that more capacity did not automatically improve performance here.

## Stability
1. Seed-to-seed variance is low across all four models.
2. This suggests the benchmark is stable and not dominated by one lucky run.
3. Some runs stopped before epoch 30 because of early stopping, which is expected under the chosen training protocol.

## Main confusion patterns
1. Errors are concentrated in visually similar tomato disease classes rather than across crops.
2. The most repeated confusion pairs are:
   - `Tomato - Target Spot -> Tomato - Spider Mites`
   - `Tomato - Early Blight -> Tomato - Late Blight`
   - `Tomato - Late Blight -> Tomato - Early Blight`
   - `Tomato - Yellow Leaf Curl Virus -> Tomato - Bacterial Spot`
3. These are useful discussion points for later qualitative analysis and XAI interpretation.

## Graph Guide
Generated by:
```bash
py -3.13 -m src.phase2_analysis
```

Outputs live under `results/phase2/analysis/plots/`.

### `metric_summary.png`
1. Shows mean test accuracy and macro F1 for each model with error bars for standard deviation across seeds.
2. Use this as the main overview figure for ranking.

### `seed_variance.png`
1. Shows the individual seed results for accuracy and macro F1.
2. Use this to support the claim that performance is consistent across seeds.

### `efficiency_tradeoff.png`
1. Compares model size and macro F1, with parameter count encoded in the plot.
2. Use this to argue about “best overall” versus “best efficiency/performance trade-off.”

### `loss_curves.png`
1. Shows train and validation loss over epochs for each model across seeds.
2. Use this to discuss convergence behavior, stability, and early stopping.

### `accuracy_curves.png`
1. Shows train and validation accuracy over epochs for each model across seeds.
2. Useful for demonstrating learning behavior and possible ceiling effects.

### `mean_confusion_heatmaps.png`
1. Shows row-normalized mean confusion heatmaps per model.
2. Use this to identify which classes remain difficult even after high overall accuracy.

### `top_confusions.png`
1. Aggregates the most common off-diagonal confusion pairs across all runs.
2. Useful for quickly identifying the biologically/visually similar disease categories that still cause mistakes.

2. At the moment, local checkpoint hashes do **not** match the imported Colab run artifacts.
3. So image-level wrong-prediction galleries should currently be generated either:
   - after exporting the matching model checkpoints from Colab, or
   - directly in the Colab environment where the checkpoints were created.

## What to write in the report
1. State that all four architectures achieved very high performance on PlantVillage, indicating the task is highly learnable under controlled image conditions.
2. Emphasize that `resnet18` provided the strongest overall balance of performance and model size.
3. Discuss `efficientnet_b0` as the most efficient near-top performer.
4. Note that the ViT did not dominate the CNNs on this dataset, which is a meaningful empirical result rather than a weakness.
5. Frame the remaining errors as fine-grained disease confusions within tomato classes, not broad failures of the classification pipeline.
