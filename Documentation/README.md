# Documentation Index

## Purpose
Organized project documentation and planning notes, grouped by function and project phase.

## Folder Structure
1. `Documentation/plans/`
   - Implementation plans and planning revisions.
2. `Documentation/docs/`
   - Living documentation and lab log.
3. `Documentation/reviews/`
   - External or third-party review outputs.
4. `Documentation/phase1/`
   - Phase 1 checklists and sign-off files.
5. `Documentation/phase2/`
   - Phase 2 execution checklists and gate tracking.
6. `Documentation/phase3/`
   - Research Phase 3 planning plus the boundary with the separate Verdanta
     product repository.
7. `Documentation/archive/`
   - Resolved/legacy notes kept for reference.

## Notes
1. Keep active execution checklists under phase folders.
2. Keep narrative history in `Documentation/docs/documentation.md`.
3. Record dated execution notes in `Documentation/docs/lab_log.md`.
4. Keep product deployment code and private model weights outside this research
   repository. Only governed export tooling and reproducible research notebooks
   belong here.
