# Markdown Files Index

## Purpose
Organized project documentation and planning notes, grouped by function and project phase.

## Folder Structure
1. `Markdown Files/plans/`
   - Implementation plans and planning revisions.
2. `Markdown Files/docs/`
   - Living documentation and lab log.
3. `Markdown Files/reviews/`
   - External or third-party review outputs.
4. `Markdown Files/phase1/`
   - Phase 1 checklists and sign-off files.
5. `Markdown Files/phase2/`
   - Phase 2 execution checklists and gate tracking.
6. `Markdown Files/phase3/`
   - Reserved for Phase 3 planning/checklists.
7. `Markdown Files/archive/`
   - Resolved/legacy notes kept for reference.

## Notes
1. Keep active execution checklists under phase folders.
2. Keep narrative history in `Markdown Files/docs/documentation.md`.
3. Record dated execution notes in `Markdown Files/docs/lab_log.md`.
